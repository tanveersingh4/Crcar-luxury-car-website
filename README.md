# CRCAR — Drive Beyond Limits

A premium luxury automotive website designed to showcase extraordinary vehicles through a cinematic and elegant digital experience.

## Live Demo

**Website:** https://cr-car.netlify.app/

## Overview

CRCAR is a luxury car rental website concept focused on premium vehicles, sophisticated presentation, and an exclusive automotive experience.

## Features

- Premium luxury car collection showcase
- Featured vehicles with specifications and rental pricing
- Cinematic automotive presentation
- Luxury brand showcase
- Customer testimonials section
- Premium service and membership highlights
- Contact and booking call-to-action sections
- Modern, visually immersive user interface

## Featured Vehicles

- Ferrari SF90 Stradale
- Lamborghini Huracán EVO
- Rolls-Royce Ghost
- Porsche 911 GT3 RS
- Bentley Continental GT

## Project Goals

- Create a polished luxury automotive web experience
- Present vehicle information through an elegant layout
- Build a visually engaging and user-friendly interface
- Showcase modern website design and frontend development skills

## Deployment

This project is deployed on Netlify.

**Live URL:** https://cr-car.netlify.app/

## Note

This repository showcases the website's design and presentation. Booking, payment, and other backend functionality should not be considered operational unless separately implemented and verified.
